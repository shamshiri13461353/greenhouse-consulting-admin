# پنل مدیریت کارشناسان

این پنل آزمایشی به پروژه Supabase با شناسه `tnfunhkxnldrylwbxraf` متصل است.

## اجرا
فایل `index.html` را از طریق یک وب‌سرور محلی یا میزبانی استاتیک باز کنید؛ برای نمونه در VS Code از افزونه Live Server استفاده کنید. به‌دلیل استفاده از ES module و Supabase JS، باز کردن مستقیم فایل با آدرس `file://` توصیه نمی‌شود.

## قابلیت‌های نسخه اولیه
- ورود مدیر با ایمیل و گذرواژه Supabase Auth
- بررسی نقش `admin` و وضعیت فعال حساب
- مشاهده فهرست پروفایل کارشناسان
- دعوت کارشناس از طریق Edge Function با نام `admin-invite-expert`
- تأیید کارشناس پس از پذیرش دعوت با RPC `admin_approve_expert`

## ملاحظات امنیتی
- کلید موجود در فایل، کلید عمومی publishable است و مجوز مدیریتی ایجاد نمی‌کند.
- هرگز کلید `service_role` یا secret key را در این پوشه یا مرورگر قرار ندهید.
- کنترل دسترسی باید در Edge Function، RPC و RLS پایگاه داده باقی بماند؛ پنهان‌کردن دکمه‌ها در رابط کاربری کنترل امنیتی محسوب نمی‌شود.
- ارسال واقعی ایمیل دعوت به تنظیمات SMTP و URLهای مجاز Redirect در Supabase Auth وابسته است.
- قبل از استفاده عملیاتی، این پنل باید با حساب مدیر واقعی و یک ایمیل آزمایشی کنترل‌شده آزمون شود.
- این نسخه فقط دعوت و تأیید کارشناسان را پوشش می‌دهد؛ ویرایش مشخصات، تعلیق/لغو دسترسی و گزارش رویدادهای مدیریتی در گام‌های بعد اضافه می‌شوند.
